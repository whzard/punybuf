# Retiring value enums
This proposal aims to remove value enums and replace them with a different syntax.

## Use
Currently, value enums are a special kind of syntax for enums for enums whose variant names are the same as the values inside them, like
```pbd
ValEnum = (
	String, U64, MyStruct
)
```
Which desugars into:
```pbd
ValEnum = [
	String: String,
	U64: U64,
	MyStruct: MyStruct
]
```

While a useful feature in theory, it makes refactoring code more difficult and it's impossible to add empty variants to value enums.

A better approach would be to allow individual variants to inherit the names of their values.

## Proposed syntax
```pbd
ValEnum = [
	(String),
	(U64),
	OtherName: MyStruct
]
```

Or:
```pbd
ValEnum = [
	[String],
	[U64],
	OtherName: MyStruct
]
```
Looks nicer, but nor exactly clear whether it's an inline declaration or not.


Or:
```pbd
ValEnum = [
	:String,
	:U64,
	OtherName: MyStruct
]
```

Very weird having nothing before the `:`
